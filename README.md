## Как запустить
1. Открыть https://www.onlinegdb.com/online_python_compiler
2. Удалить пример кода и вставить содержимое `main.py` (или нажать **Copy raw file** в GitHub).
3. Нажать **Run** и вводить данные в консоли внизу, после каждого значения — Enter.
